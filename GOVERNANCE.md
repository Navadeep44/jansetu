# Governance

JanSetu is maintained as an open Digital Public Good.

- **Maintainers:** the founding hackathon team (see git history). New maintainers are added by consensus of existing maintainers.
- **Decisions:** proposals are made as GitHub issues or pull requests and merged after review by one maintainer (two for security or privacy-relevant changes).
- **Country nodes:** each deploying government owns its node, its data and its configuration. The core codebase stays neutral and open.
- **Security:** report vulnerabilities privately to the maintainers. Do not open public issues for them.
- **Licence:** contributions are accepted under Apache-2.0 (code) and CC-BY-4.0 (docs and data).
